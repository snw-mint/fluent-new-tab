Privacy Policy

Last Updated: November 2026

This policy describes how Fluent New Tab handles data, browser permissions, and network requests. It reflects the current implementation in the extension's source code.

1. Data Collection

Fluent New Tab does not collect, sell, or transmit personal data to developer-controlled servers, and does not include analytics, telemetry, or tracking scripts.

2. Local Storage

All configuration and user-created content are stored locally on your device using browser storage APIs (no cloud sync via chrome.storage.sync is used):

  • localStorage: Preferences, theme and accent settings, custom greeting name, language, shortcuts, selected weather city, and configured RSS/Atom feed URLs.
  • chrome.storage.local: Favicon cache (14-day TTL), selected city coordinates for background weather alerts, the latest evaluated weather alert, and local update-notice flags.
  • IndexedDB: Custom wallpaper images uploaded from your device.
  • Manual Backups: You can export and import your settings as a local JSON file; this file is generated and read entirely on your device.

3. External Services & Network Requests

External network requests occur only when you enable or use specific features. Most requests go directly from your browser to the respective provider:

  • Search Suggestions: When enabled, typed queries are sent to DuckDuckGo (duckduckgo.com/ac/) to fetch autocomplete suggestions.
  • Weather & Weather Alerts: The extension does not use browser GPS/geolocation. When you search for a city or enable weather/alerts, the city query or manually selected coordinates are sent to Open-Meteo (geocoding-api.open-meteo.com, api.open-meteo.com, and air-quality-api.open-meteo.com).
  • Direct Wallpaper Providers: Daily wallpapers are fetched directly from peapix.com / img.peapix.com (Bing) or commons.wikimedia.org / upload.wikimedia.org (Wikimedia Commons).
  • Proxied Wallpaper Providers: Unsplash and Pexels requests are routed through Cloudflare Workers (unsplash.snw-mint.workers.dev and pexels.snw-mint.workers.dev) solely to protect API credentials and handle rate limits. These workers do not log or store personal data or tracking identifiers.
  • RSS/Atom Feeds: When you add custom feeds, the extension fetches those feed URLs directly from your browser.
  • Favicons: On Chromium-based browsers, shortcut icons are resolved locally using Chrome's built-in favicon API whenever available. For RSS feed sources and as a fallback when the native API is unavailable (such as on Firefox), only the site's domain is requested from favicon.vemetric.com.
  • Voice Search: When triggered by the user, voice input uses the browser's native Web Speech API (SpeechRecognition), which is processed according to your browser and operating system's speech service.
  • Uninstall Page: Upon uninstallation, the browser opens https://snw-mint.github.io/fluent-new-tab/uninstall.html via chrome.runtime.setUninstallURL.

Required Permissions

  • storage and unlimitedStorage: Store settings, cached metadata, and user-uploaded wallpapers locally.
  • search: Execute searches using your browser's default search engine when the "System" search option is selected.
  • alarms: Schedule hourly background checks (every 60 minutes) for weather alerts, active only when Weather Alerts are enabled.
  • favicon (Chrome): Resolve shortcut favicons locally without sending shortcut URLs to external services.

Optional Permissions

Optional API and host permissions are not granted at installation and are requested only when you enable or trigger the corresponding feature:

  • bookmarks: Requested only when you click to import browser bookmarks into your shortcuts.
  • Host permissions: Requested individually for duckduckgo.com (search suggestions), open-meteo.com endpoints (weather and alerts), peapix.com / commons.wikimedia.org / snw-mint.workers.dev (wallpaper sources), and user-added https://*/* origins (RSS/Atom feeds).

5. Managing & Deleting Data

Because all data is stored locally, you can remove it at any time by:

  1. Using the reset option in the extension settings.
  2. Clearing the extension's local storage/site data in your browser.
  3. Uninstalling the extension, which removes its local storage.
